# 结果交接与溯源

用于接收分析产物、核对数字和处理版本差异。输入可以来自任意分析工具或人工整理，不要求使用特定分析 skill。不存在结果清单时，从现有文件建立；只有不足以完成当前写作的关键字段才补问。

## 读取材料

优先使用用户指定的研究方案/定义、数据字典、执行记录、结果表与图、模型导出或经确认的总结。当前有效版本和状态要能区分，不能把“最新文件名”自动视为最终分析。代码能说明计划或实现，不能单独证明已成功执行；不为查明版本而自动重跑代码或模型。

原始统计输出与摘要矛盾时，核查对应人群、终点、模型、时距、处理方案和时间版本；无法解决则保留冲突及其来源，暂不为该处选一个好看的数字。其余有依据的段落可继续。

对表格可以做合计、比例、单位和四舍五入核对，但须保留原始值与计算依据；这些核对不是新增效应估计。受限于输入精度的数值不恢复虚假小数位，不反推未保存的超参数或未提供的统计量。

## 最小结果清单

清单留在当前研究目录，格式可以是 Markdown、表格或等价结构。一个结果可以跨多行表示，下列斜线是字段组合含义，不要求使用含斜线的机器键。

| 交接字段 | 内容 |
| --- | --- |
| result_id | 当前版本中唯一且稳定的结果标识，用来连接稿件论点与输出 |
| analysis/status | 分析名称及状态：已完成、未做、失败、计划中或未提供；区分“未提供”与“未做” |
| population/endpoint | 分析人群、终点定义/编码、时间零点、预测时距或随访单位、分析人数及事件数；按当前论点记录必要项 |
| specification | 实际模型/方法、指标尺度、参考值/组、调整变量、插补与合并方式、验证设计等解释所需设置 |
| estimate | 真实效应或性能、区间、必要P值及精度；有多个时距/模型时分别标记；未估计时写明原因 |
| source | 文件、sheet/表行、图/模型导出或执行记录位置及版本；来源需足以回到具体结果 |
| qualification | 诊断/警告、敏感性差异、探索性、删失/竞争风险处理、缺失信息与可解释范围 |

分析侧已经提供这些语义时直接复用，不要求重排文件。普通表格缺少元数据时可结合方案和执行记录补足；不能仅凭结果形态猜模型。没有任何统计输出时，可以整理提纲或非结果段落，但不能编写数值结果。

## 三类证据分别管理

- **研究定义和执行事实**：设计、指标公式/成分/单位、采样窗口、真实纳排、时间零点、终点和实际方法。方案中的拟用方法须与执行记录核对。
- **本研究结果**：样本/事件数、效应、区间、诊断、性能与验证。关联估计、内部预测评价、外部验证和更新后的模型分开标记，不互相借用结论。
- **外部文献**：背景、机制、既有研究和方法依据。每项关键论点有对应来源，不把文献报告的结果当成本研究结果。

伦理审批/豁免、知情同意、数据权限、登记和资金/利益冲突等只按真实信息写，未提供时列待补；不要用示例机构、编号或通用句替代事实。

## 易混淆项

| 情况 | 写作处理 |
| --- | --- |
| 模型之间样本/事件数变化 | 说明完整案例/可用数据等原因；不把效应变化全归于调整变量 |
| HR、SHR、OR、时间依赖AUC混在一张表 | 保留各自估计目标、尺度和时距，不统称风险预测能力 |
| 右删失或竞争事件处理未交代 | 标待核实，并限制相应风险/预测表述；不在Methods自行补上IPCW或Fine–Gray |
| 多重插补只给一张结果表 | 核实是否已合并及其方法，不能因为列名写imputed就宣称完成合并推断 |
| 外部队列重新校准/训练后性能较好 | 原模型验证、更新步骤和更新后的评价分别写，不能合并称原模型验证成功 |
| 指标由模型强制保留或SHAP排名靠前 | 按实际事实表述，不推导成独立贡献或因果作用 |
| 非显著、失败或未提供 | 分别描述；非显著不等于等效，无输出不等于无关联 |

## 表图交接

按本次研究建立需要的表图清单，记录用途、内容、源结果标识/版本、正文或补充位置及编号。编号在当前稿件内统一，不继承旧项目的固定页数或图号。

流程图中的纳排可与人数核查记录对应，排除原因有重叠时解释其计数方式；不同终点/外部队列的分析样本变化需可追踪。图题与脚注明确单位、参考组、调整、区间、风险人数/分母及必要缩写。

逐行预测、身份标识和个体解释原始矩阵不自动附入稿件；必要个体示例去标识并说明选择规则。对现有图表只做请求范围内的整理和说明，不擅自重绘成未验证的新模型结果。
