# 写作前准备与研究主线

用于首次全文起草、研究定位、Introduction/Discussion 的文献准备或对标选择。只做单段润色、翻译或已有文本格式修改时，不自动扩大到完整文献调研。

## 1. 先看真实研究，再安排文章

读取用户提供的方案、方法记录、结果总结、主要统计表和图；有结果清单则复用，没有则按 [结果交接与溯源](result-handoff.md) 建立。先回答：研究问了什么、实际做了什么、发现了什么、哪些结果最可靠、哪些问题尚未解决。

整理下列当前写作需要的资料；未知项分别标明，不要求一次收齐才能写其他段落：

- 人群、中心/数据来源、时间范围、纳排与时间零点，指标公式/成分/单位/采样时点。
- 主要研究目标、主次终点、随访、分析人数/事件数、主要估计与区间，阴性及诊断异常。
- 关联分析、预测开发、内部评价、外部验证、模型更新各自是否实际完成，使用何种人群和版本。
- 主要表图、补充材料、已有文献、目标期刊、篇幅/结构、语言和交付范围。

外部验证有、没有、未提供是三种状态。有则收集相应人群、定义、方法与结果；明确没有则据实讨论；状态未知且影响全文定位时合并补问一次。不要在题目或摘要提前写成已有外部验证。

## 2. 文献准备：三类证据，服务具体论点

沿用三类组织方式，但覆盖度由研究问题决定，不用固定篇数或近年占比替代充分性：

| 文献类别 | 需要回答的问题 | 阅读重点 |
| --- | --- | --- |
| 经典/基础 | 疾病与结局为何重要，指标如何提出，其成分有什么已知含义 | 定义、公式、基础机制、临床场景及证据范围 |
| 当前进展 | 同一人群与终点已有何发现，哪些问题仍有争议 | 结果一致与不一致、现有模型/标准、可比性和证据限制 |
| 同方向对标 | 与本研究最接近的研究如何组织证据和报告结果 | 研究设计、队列、终点、调整/验证、主要表图、讨论逻辑 |

使用指标全称、缩写、成分、疾病和终点同义词组合检索；必要时把关联和预测分别搜索，避免只找到支持主张的一面。可从下列搜索骨架出发，按平台语法调整：

```text
{marker full name OR abbreviation} AND {condition} AND {outcome}
{marker OR component names} AND {condition} AND {prognosis OR survival}
{condition} AND {outcome} AND {prediction model OR external validation}
```

记录检索日期、平台、检索范围和访问限制。时间范围覆盖当前进展并保留必要经典文献，不能写死历史年份。用引用追踪补充重要原始研究，普通背景检索不声称为系统综述。

### 文献证据表

按实际需要记录：

| 字段 | 要提取的内容 |
| --- | --- |
| 文献身份 | 作者、年份、标题、期刊、DOI/PMID，实际访问层级（全文/摘要/二手） |
| 设计与人群 | 研究类型、来源、样本/事件规模、关键纳排和治疗场景 |
| 指标与结局 | 公式、单位、采样时点、暴露处理、终点/时间零点及随访 |
| 方法与结果 | 调整/验证设计，支持该论点的效应或性能及其区间 |
| 局限与可比性 | 缺失、偏倚、验证、人群和测量差异，不能直接比较之处 |
| 本文用途 | 支持背景、界定空白、解释一致/差异、方法依据或反方证据 |
| 证据位置 | 对应页、段、表、图或摘要位置，足以回到具体论点 |

不能只复制摘要结论。用于核心论点的论文优先核对原文定义和关键表图；全文不可访问时保留依据限制，不声称已精读。

## 3. 选择核心对标文献

通常可先选少量最贴近的论文作为结构参照，例如两三篇；找不到高度可比论文就说明差异，不为凑数量降低标准。优先顺序是研究问题和设计匹配，其次人群/终点/测量/验证方式，再考虑目标期刊的体例与篇幅。

对每篇说明“为什么选、哪些部分可借鉴、哪些部分不能照搬”。可借鉴问题推进、方法小标题和表图组织；不能套用其纳排、模型、结果或结论，也不通过同义词替换复制句子。对标文献不是唯一证据来源，保留相反发现。

输出可以是当前项目的一张对标表或文献笔记。文件名和目录按项目约定，不引用作者私人研究路径。

## 4. 从优势清单形成有证据的研究主线

保留原工作流围绕研究贡献组织全文的思路：让读者清楚本研究回答了什么、相对已有证据增加了什么。贡献数量由证据决定，不能把每种算法或敏感性分析都包装为单独优势。

| 候选贡献 | 需要核对的依据 | 适合的表述边界 |
| --- | --- | --- |
| 特定人群/终点证据 | 已有研究的覆盖范围与本研究实际人群、终点 | 写清具体补充了哪个场景，检索不到不证明首次 |
| 数据规模/多中心/随访 | 与可比文献的样本、事件和随访对照 | 说明覆盖度和精度的潜在收益，不自动声称可推广或无偏 |
| 指标的测量和临床可得性 | 实际成分、采样、成本/可得性依据 | 简便可测不等于预测有效或可指导决策 |
| 关联/非线性发现 | 预设模型、效应及区间、诊断、敏感性 | 区分调整关联与独立因果作用，不把弯折直接称临床切点 |
| 增量预测/验证 | 基础与加指标模型的相同评价设计及真实结果 | 只描述已证实的增量、校准与适用范围；外部下降也是发现 |

建立“贡献—文献依据—本研究结果标识—局限—允许措辞”的对应关系。发现优势不足时，收窄研究主张或以不确定性/阴性发现定位，不要求为了可发表而补造价值。

### 写作前的简短定位稿

先用几句话或一张表列出研究问题、主要发现、可支持的贡献、对标文献和主要限制，再据此安排各章节。每项核心结论要能同时对应 Introduction 的问题、Results 的结果和 Discussion 的解释。

如用户已约定先确认定位，则在该节点一次汇总供其确认；若定位和授权已清楚，直接继续，不把对标和每个章节分别设成审批关卡。关键证据缺失时只暂停依赖它的结论。

## 5. 写作顺序与阶段产物

默认可沿用“暂定题目与关键词→Introduction→Methods→Results→Discussion/局限/结论→Abstract→全文复核”的顺序。所有章节先依托已核对的结果；若结果或方法复杂，也可先完成 Methods/Results，再写 Introduction。摘要在正文和关键数字稳定后完成，题目最后回看一次。

整篇任务通常形成下列有实际用途的材料，已有文件可直接更新，不要求拆出多个新文件：文献证据笔记、研究主线与对标、结果清单、正文草稿、表图清单、未核实事项及复核记录。单章任务只交付相关材料。

每完成一个章节，按 [逐章写作指南](manuscript-workflow.md) 核对其论点、证据和逻辑，再推进下一章。复核职责保留，不强制指定工具或三个代理；发现问题可直接修正有依据的文字，涉及结果/设计变更则明确需要另行处理。
