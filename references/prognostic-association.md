# 预后关联分析

用于估计复合指标与结局的关系。先确认研究定义及数据核查充分；新增数据/终点时按需读取 [研究定义与数据](study-design-and-data.md)。关联显著不等于个体风险模型已经有效。

## 主要分析

1. 根据终点选择模型。右删失时间结局可用合适的生存模型；完整固定时距二分类可选相应回归；重复事件、时变暴露或多状态问题需要匹配其结构的方案，不能直接套首次事件 Cox。
2. 预设主要暴露形式及协变量调整集。按临床知识、时间关系与估计目标选择协变量，不固定四套模型，不以单因素P值机械筛选混杂因素。区分混杂、中介、碰撞变量和指标成分，说明为何纳入/排除。
3. 连续效应按有意义的单位、SD或IQR报告，记录尺度所用参考样本。分组可补充展示，明确参考组和切点；有序趋势检验仅在问题适用时做，并说明采用组序数或组内代表值，不强制所有表都加趋势P值。
4. 报告效应量、置信区间、分析人数/事件数和调整变量。对多重插补后的模型合并推断，说明不同模型若样本改变，其估计差异同时可能来自样本变化。

## 曲线与模型诊断

- **KM**：用于合适的生存概率展示，提供随访尺度、风险人数及必要区间；尾部稀疏时限制解释。生存曲线组间检验不能替代调整模型。
- **Cox**：检查模型拟合警告、分离/稀疏、连续变量函数形式、变量级和全局 PH 诊断及图形。P>0.05不能证明 PH 成立；必要时采用时变效应、分层或其他合适模型并调整解释。
- **共线性**：结合设计矩阵、变量定义与不稳定估计判断，区分 VIF 和多自由度 GVIF；不以单一阈值宣布完全无共线性。
- **非线性/RCS**：复杂度由样本量、取值数、分布和预设方案决定，记录结点与参考值，画效应及区间并显示数据支持。离散少值评分不自动套连续样条。
- 报告总体关联和非线性证据，非显著非线性检验不证明线性。不强制标“拐点”；二阶导数绝对值最大不是数学拐点，也不自动提供临床切点。确需阈值研究时单独定义估计目标、方法、不确定性与验证。

## 竞争风险与累积风险

是否处理竞争事件取决于终点和时间顺序，不取决于主分析显著性。根据数据核对目标事件、竞争事件和删失的首次发生时间；仅有总随访时间与几个最终标志时，不假定已足以构造所有终点。

存在竞争事件时，目标事件实际累积发生风险使用 CIF 等合适方法；不能统一以1−KM替代。根据研究问题选择 cause-specific hazard 或 subdistribution hazard 模型，并明确报告 HR 或 SHR 的含义。Fine–Gray不是所有非全因死亡结局的必选项；全因死亡也不机械设置其他死亡为竞争事件。参考：[BMJ：存在竞争事件时的风险解释](https://www.bmj.com/content/349/bmj.g5060.long)。

## 条件触发的敏感性与探索分析

| 模块 | 何时使用 | 实施及解释要点 |
| --- | --- | --- |
| 亚组/交互 | 预设异质性问题或有依据的探索 | 亚组及切点有临床理由；优先效应和交互及区间，不以一组显著另一组不显著判定交互。说明多重性与探索性质；样本稀少时简化/不估计，不凭HR数值范围判断收敛 |
| 界标 | 研究存活/无事件到特定时点者的后续风险 | 每个界标和终点分别确定仍在观察且满足风险集条件的人群，重置时间。首次非致死终点须界标前未发生该终点；精确说明天/月单位。它改变目标人群，不能据一致性自动断言原结论稳健 |
| 中心影响 | 多中心结构可能影响估计 | 按问题与中心/事件数选择分层、固定/随机效应、稳健方差或删中心分析。少数聚类时谨慎用渐近稳健方差；比较效应及精度，去中心后P变不显著不自动等于偏倚 |
| 缺失/异常处理 | 主要结论依赖处理假设 | 与完整案例、合理替代插补或异常值处理比较，说明样本和假设变化，不以显著性挑选主方案 |
| PS匹配/加权 | 明确暴露/治疗的因果估计问题 | 先定义处理、目标效应、时序、混杂与重叠性，再匹配/加权并按设计推断；不默认用未来event/non-event做PSM后比较指标来“证明预后价值” |
| 中介 | 有独立因果假设且有适当时序和数据 | 先明确暴露、中介、结局、效应尺度、混杂假设与方法适用条件；SHAP排名不能确定因果方向，不用P值衰减证明上游作用 |

生存中介分析不能通用地把线性模型与 Cox 系数相乘后称为自然间接效应；bootstrap只评估既定估计量的不确定性，不修复因果识别问题。参考：[VanderWeele：生存数据的因果中介](https://pmc.ncbi.nlm.nih.gov/articles/PMC3109321/)。

## 结果交接

保留实际执行的模型、公式、暴露尺度、参考值、样本/事件数、估计与区间、插补合并方法、诊断警告及敏感性差异。阴性、估计不稳定或无法拟合都是可报告结果；不通过换分组/终点追逐显著性。
