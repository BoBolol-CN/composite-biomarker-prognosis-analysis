# 研究定义与数据

用于启动研究、理解新数据或复核数据处理。已有充分定义时，只核对变更部分。本分析参考止于分析方案、数据和结果交接，不承担论文起草。

## 最小研究定义

从方案、数据字典和会话提取下列信息，保存在当前研究的配置或方案文件中。字段可因任务删减；缺少关键定义时提出一个合并问题，不重复询问已有答案。

| 类别 | 需明确的信息 |
| --- | --- |
| 目标 | 预后关联、增量预测价值、模型开发、外部验证或结果复核；主要与探索性分析 |
| 队列 | 数据来源、设计、目标人群、纳排标准、时间范围、中心与患者标识、重复测量或重复入组 |
| 时间 | 纳入日/手术日等时间零点，指标采集窗口、预测时点、随访终止及日期/时间单位 |
| 主指标 | 名称、公式/原始出处、成分列、单位、适用范围、连续或评分类型、缺失/非法值处理 |
| 结局 | 主次终点定义、事件与删失编码、各自时间列、复合终点构成及首次事件、竞争事件、预测时距 |
| 协变量 | 定义、编码、采样时间、选择理由、是否在预测时可获得、与指标成分的关系 |
| 分析 | 关联模型与调整集，分组/切点与连续效应尺度，缺失和异常处理，验证设计及必要敏感性分析 |
| 交付 | 输出位置、语言、所需文件/图表格式、结果使用场景及本地执行环境 |

区分缺少真实定义与可由程序探测的信息。列名、数据类型、缺失率、可用包版本可直接检查；列中数字代表何种疾病分级、时间零点是什么等不能靠猜。

## 数据与队列核查

- 核对行的含义、标识唯一性、重复入组及多个文件连接键。中心和患者标识用于分组/聚类/审计，不作为普通预测特征。
- 原始文件保持可追溯。派生数据由代码生成，保存源文件版本或摘要及纳排日志，避免旧结果混入本次输出。
- 对齐变量先核对临床定义、时间窗、单位和类别含义，再映射列名。分级转二分类是重新编码，不能当作简单 rename；映射规则写入项目配置。
- 验证事件与时间的组合、非正随访、事件发生在时间零点之前、死亡与非致死事件先后、随访不足及结局缺失。发现矛盾先核查，不能自动把未知结局填成未发生。
- 对复合终点计算各构成事件的首次符合定义时间。死亡若已包含在复合终点内，不再机械地把同一次死亡标成竞争事件。并列事件规则预先说明。
- 复合指标核对公式、单位和分母零/近零。指标与成分保持确定性关系，保留计算记录；真实极端值与录入/测量错误分开处理。
- 队列流程反映所有真实纳排环节，各步骤人数和重叠原因能核对。不同终点/模型样本不同时分别报告人数及事件数。

## 缺失数据：按目标分流

先描述每变量/成分缺失率、联合缺失模式、中心/时间差异、原因和缺失后的人群变化。不能用统一20%界线决定删除，也不能因为主指标是研究对象就一律禁止合理插补。缺失处理应与可辩护的假设及研究目的相容。

**关联推断：** 根据缺失机制与分析模型，选择多重插补、完整案例或其他有依据的方案。设计插补模型时考虑结局与随访信息、非线性/交互、中心结构及辅助变量；需时使用与实体模型相容的方法。不要把预测部署的限制错误地搬到推断插补中。按变量类型选择方法，检查链稳定性、分布合理性和必要的敏感性分析；插补份数/迭代数以信息缺失及诊断为依据，不固定小参数。

在各份插补数据上拟合分析模型，恰当合并参数、方差与检验；不能直接平均完成数据或只拿其中一份推断。派生比值/评分在每份数据内重算或采用合适的被动插补/相容方法，检查公式一致性。结局或删失信息缺失需要单独方案，不能随普通基线变量盲目插补。

**预测开发与评价：** 先明确划分/重采样边界。数据驱动的插补和预处理在各开发折内估计，再应用到相应评价折；最终测试/外部结局不得参与预测输入生成。预测时的缺失处理应可在实际使用条件下执行。研究性外部多重插补可有独立设计，但应说明与部署策略的区别及其对评价的影响，不能把外部结局辅助生成的输入称为真实可部署预测。

参考：[mice 插补方法与派生变量处理](https://amices.org/mice/reference/mice.html)、[多重插补后合并估计](https://amices.org/mice/reference/pool.html)。

## 异常值、分组与描述

- 优先核查错误及单位；真实极端值可保留、合理变换或依方案处理，同时评估敏感性。不默认对所有指标缩尾。
- 数据驱动截尾/缩放若是预测流程的一部分，保留开发数据估计的参数并用于后续预测。不能仅因称其为“清洗”就在测试或外部队列重新估计。
- 连续暴露通常保留连续信息；分组须有展示或临床依据，不强制三/四分位。分位切点只在定义的参考样本计算一次，明确并列值、实际组数和边界归属；主分析与分层分析需要同一切点时复用数值，而非各层重算。
- 基线表按研究需要分组，连续变量和分类变量用适合的描述统计；保留缺失数和正确分母。是否展示组间检验/SMD按设计与期刊决定，不把平衡或不显著当作无混杂/可迁移的证明。
- 外部模型所需特征的可用性不限制主队列所有描述变量；外部队列缺少模型变量时先评估可比性和验证可行性，不悄悄删特征、改定义或重训练后仍称原模型验证。

交付至少包含当前任务需要的数据映射、队列及事件核查、缺失/异常处理决定。可按需生成基线表与清洗数据，但不要把患者级资料带入可分享的 skill 包。
