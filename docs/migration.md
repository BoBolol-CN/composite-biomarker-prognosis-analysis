# 从项目脚本到通用模块

本版本保留数据处理、关联、竞争风险和预测验证的主要工作，重构为函数与配置。旧脚本不会原样进入公开仓库；原项目文件及数据保留在作者本地。以下映射说明能力去向，不声称所有旧步骤均已自动化迁移。

| 原脚本/步骤 | 通用实现 | 改变 |
| --- | --- | --- |
| 01数据清洗 | `core.R`、`assets/config.example.R` | 去除固定疾病编码、指标、数据文件名和强制缩尾；指标由可信配置函数定义 |
| 02基线、缺失汇总、分组基线 | `run_baseline()` | 变量和分组动态生成，保留缺失分母；不把阈值规则当作实际执行记录 |
| 04 KM、09固定时点风险 | `run_km()` | 同一分组切点，风险人数与曲线共享时间尺度；不外推到无支持时距 |
| 05 Cox、PH、VIF | `run_cox()` | 调整集与模型数量可配置，分组/连续形式可选，输出样本及警告；VIF明确为设计列级诊断 |
| 06样条 | `run_spline()` | 自然立方样条及嵌套似然比检验；去除把参考值HR=1或最大二阶导称作临床切点的代码 |
| 07普通ROC | 预测模块对应时距的ROC | 删失结局用合适的时距权重；不把随访中曾发生直接当完整二分类 |
| 08亚组交互 | `run_sensitivity()` | 因子和切点须由研究配置明确；结果同时保留交互与失败信息 |
| 10 PSM | 未作为通用预后敏感性模块迁移 | 原来的按未来结局匹配不能直接用于证明预后价值；明确因果问题后另行设计 |
| 11竞争风险 | `first_event()`、`run_competing()` | 先根据真实时间构造状态，再做CIF/Gray/Fine–Gray，不按显著性选择是否处理竞争风险 |
| 11b界标 | `run_sensitivity()` | 每一终点按其首次事件时间建立界标风险集，不用向量回收混跑两个界标 |
| 中心敏感性 | `run_sensitivity()` | cluster/strata/fixed/leave-one-out按配置选择，不要求四种全部运行或所有P都显著 |
| 12划分、13分组描述 | `prediction_split()`、`development_folds()` | 划分发生在数据驱动预处理前，可按组或时间保留测试；不硬编码7:3 |
| 14 LASSO | `ridge`适配器的alpha/lambda候选网格 | 正则化筛选处于开发折内；不因指标未选中而事后强制，并称“筛选证实” |
| 15多算法 | `fit_candidate()`、`predict_candidate()` | 通用模型适配器，缺包/失败明确记录；不会用测试集事件率制造常数“模型”预测 |
| 16评价、16b图、校准模板 | `evaluate_predictions()`、`make_gallery()` | 匹配时距与删失，冻结预测bootstrap；不设树模型校准豁免，不裁掉真实高风险范围 |
| 17 SHAP/列线图 | 暂未封装为通用自动模块 | 需要解释同一冻结模型、正确基准值和尺度；不能靠重新拟合普通回归冒充原模型展示 |
| 18 SHAP后中介 | 暂未封装为通用自动模块 | 排名不决定因果图，生存中介需效应定义和识别假设；不把P值衰减当机制证明 |
| 19 PPT | 交付真实PNG/PDF，PPT按实际需求另行整理 | 不依赖旧项目固定页码、终点和图号 |

R运行器当前是单行/患者的首次事件分析。复杂重复事件、多状态、时变暴露、竞争风险个体预测、滚动时间CV、条件删失权重及任意MI实体模型相容性不包含在自动覆盖范围内。

原代码中相互冲突的公式不能自动判断哪一个正确，因此没有选择其一作为通用默认；示例比值只是模拟研究的演示。使用时应按原始研究定义核对公式、单位和采样窗口。

可选模型版本的兼容性需在对应环境验证。本地测试覆盖Cox和七种分类适配器；XGBoost/LightGBM因本地未安装，保留为可选集成并明确未测试。不能把未测试适配器视为已验证实现。
